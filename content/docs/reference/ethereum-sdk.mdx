#### `NetworkAddresses`

Shared, wallet-family-agnostic network addresses. Both the SHRINCS family (through its own `getShrincsAddresses`) and the sunset WOTS+ family rely on the same ERC-4337 EntryPoint; the WalletFactory address is shared across every chain reached by the same operator (CreateX sender-guarded CREATE3).

#### `WotsNetworkAddresses`

WOTS+-family address set. The WOTS+ wallet family (QuipSigner, QuipClient, QuipPaymasterClient, …) moved to `./deprecated/v1`; these fields exist only for that sunset family and are not part of the shared `NetworkAddresses` surface. The live SHRINCS family resolves through `getShrincsAddresses`.
