description: Type tables for the TypeScript SDKs, and the faucet API.
---

The SDK pages are generated at build from the type declarations in the published npm packages, and each one states the package version it documents. For installation and walkthroughs, start with the [SDK guide](/docs/getting-started/quip-sdk).

- [Ethereum SDK](/docs/reference/ethereum-sdk): `@quip.network/ethereum-sdk`, the account client for EVM chains.
- [Quip Swap SDK](/docs/reference/quip-swap-sdk): `@quip.network/quip-swap-sdk`, the client for the QuipSwap Omnibus contract.
- [Faucet API](/docs/reference/faucet): request AGLS on the Aglais test network, from a server or curl.
