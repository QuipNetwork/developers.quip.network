# QUIP Extension

Quip Network publishes a QUIP extension for existing smart contracts that lets you upgrade your contracts one ABI at a time. Simply import the file using your favorite package manager and reference the extension anytime you need to unwrap a post-quantum commitment into its associated classical public key.

The primary deployer of the QUIP extension is a smart contract wallet much like a Safe, Harpie, or Magna wallet, which wraps any contract in a post-quantum signature read and aborts the subsequent contract call if the read fails.
